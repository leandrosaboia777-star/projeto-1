## Featured project — Saboia Cleaning

A bilingual React Native / Expo application for a family-run cleaning business, backed by Supabase.

- House profiles, private photo records, and recurring schedules.
- Voice/text requests with editable proposals and human confirmation.
- Manager/employee access boundaries and protected property access details.
- English/Portuguese UI, mobile reminders, and an iOS Share Extension.
- Internal iPhone builds and documented automated validation.

**My role:** product ownership, requirements, user feedback, integration setup, acceptance testing, and delivery decisions. Coding, debugging, tests, documentation, and visual adaptation were developed with substantial AI assistance.
